RUSSELLPC Backup - Privacy Policy

Effective October 18, 2026

What it is

A personal backup tool used only by its owner on his own computer. It is not offered to anyone else.

What it accesses

Only the Google Drive files it creates itself (Google's drive.file permission). It cannot see, read or change any other file in the Drive.

How the data is used

It uploads backup files and reads them back to verify or restore them. Every file is encrypted on the owner's computer before upload, so Google stores only encrypted data.

Storage and sharing

Nothing is sold, shared or sent anywhere other than the owner's own Google Drive. No analytics or tracking.

Google API Services User Data Policy

RUSSELLPC Backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
