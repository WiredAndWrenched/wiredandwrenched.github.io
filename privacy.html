Gmail Multi Drive Reader — Privacy Policy

Effective October 18, 2026

Gmail Multi Drive Reader is a private, single-user tool run by Russell Eckhout on his own computer. It is not offered to the public.

What it accesses

With the account owner's one-time approval, the tool requests read-only access to that owner's own Google Drive (drive.readonly). It can find and download files, and it cannot edit, delete, or share anything in Drive.

How the data is used

The tool's only use for a Drive file is to attach it to an email draft in the owner's own mailbox. It can combine several files into one PDF on the owner's computer before attaching. It sends nothing on its own; the owner reviews and sends every draft.

Storage and sharing

File contents are handled in memory on the owner's computer and are not stored by the tool. The access token is stored encrypted on that computer. No data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
